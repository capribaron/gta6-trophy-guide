An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: official names, descriptions and grades (verified against Exophase and PSNProfiles), a cited guide for every trophy, a five-stage roadmap to the platinum, missable warnings, and progress saved in the browser with export/import.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the guide works with the network off. Add `?demo=1` to preview it with 13 of 55 trophies earned.
